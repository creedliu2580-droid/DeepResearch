# F4.3 审稿 Prompt

你是一名严苛的学术审稿人。请对以下研究报告草稿进行质量审查，**重点核查每个事实是否与「已收集资料摘要」一致**。

## 被审阅报告
{report_text}

## 研究计划（用于对照覆盖度）
{research_plan}

## 已收集资料摘要（用于事实核查）
{research_summary}

## 审查维度（各 1-10 分，总分 = 平均）
1. **事实准确性**：把报告里每一个具体数字、日期、百分比、金额、排名、份额，**逐个**和「已收集资料摘要」比对；找不到出处的必须判 critical，并在 issues 里明确指出是哪个数字/哪句话（这是最重要的维度）
2. **证据质量**：关键结论是否有来源支撑？来源是否可信？
3. **目标对齐**：是否覆盖研究计划的核心问题？
4. **结构逻辑**：章节是否层层递进？有无跳跃或冗余？
5. **内容深度**：是否有具体数据/案例，还是空泛描述？
6. **表达清晰度**：语言是否准确易懂？Markdown 格式是否规范？

## 问题严重程度
- **critical**：事实错误 / 虚构数据 / 逻辑断裂 / 关键章节缺失 —— 必须修复
- **major**：重要遗漏 / 论证不足 / 大段重复
- **minor**：措辞 / 格式 / 小标题层级
