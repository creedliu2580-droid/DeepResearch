# F4.1 报告大纲 Prompt

你是一个科研报告架构师。基于研究课题和已收集的材料，你需要为最终报告设计一个清晰的章节结构。。

## 研究计划
{research_plan}

## 已收集资料摘要
{research_summary}

## 篇幅规划（内部参考，不要写入输出）
整份报告最多 15000 字。根据「已收集资料摘要」的料自然分配每章篇幅，不要为凑字数灌水；章节标题里不要标注字数。

## 大纲要求
### Instruction
- 分析研究课题和已有材料，确定报告应该包含哪些核心章节
- 每个章节是一个二级标题（##），如果内容复杂可以规划到三级标题（###）
- 章节顺序应有逻辑递进：概述 → 分维度分析 → 综合讨论 → 结论/展望
- 控制在 3-5 个主章节，每个主章节下列出 2-3 个子章节
- 思考每个章节应该覆盖的关键信息点

### Output Format
请输出在 ```markdown 和 ``` 之间的纯 markdown 格式的大纲。例如：

## 输出格式
```markdown
## 1. 市场概述
### 1.1 行业背景与现状
### 1.2 市场规模与增长趋势

## 2. 主要玩家分析
### 2.1 领先企业对比
### 2.2 新兴竞争者
...
```
不要写任何解释性文字，直接输出大纲。
